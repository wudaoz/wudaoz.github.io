# Publications Refresh Design

## Goal

Refresh the homepage Publications section with a concise selection of peer-reviewed papers. Emphasize publication quality, author order, and Weiheng Wu's contribution while preserving the existing visual style.

## Selected Publications

Display these five papers in reverse chronological order by year, with later 2026 venues listed first:

1. Cutting the Fuse: Actionable APT Attack Blocking in Provenance-based IDS - USENIX Security 2026
2. BTDA: A Robust Framework for Encrypted Traffic Classification with Byte-Level TLS Data Augmentation - ICASSP 2026
3. Sentient: Detecting APTs Via Capturing Indirect Dependencies and Behavioral Logic - AAAI 2026
4. SAURONEYES: Disentangling Voluminous Logs to Unveil Camouflaged Attack Intentions - IEEE TIFS 2025
5. Brewing Vodka: Distilling Pure Knowledge for Lightweight Threat Detection in Audit Logs - WWW 2025

## Presentation

- Keep the existing ordered publication list and typography.
- Make each paper title clickable.
- Prefer an official, public direct PDF URL. If no stable public PDF is available, use the official publisher or conference paper page.
- Show complete author lists in publication order.
- Bold every occurrence of `Weiheng Wu`.
- Mark both equal-contribution authors on SAURONEYES with `*` and retain the note `* indicates equal contribution.`
- Display rankings inline after each venue, for example `USENIX Security 2026 (CCF-A, CORE A*)`.

## Ranking Labels

Use the current official CCF directory and ICORE 2026 rankings:

- USENIX Security: CCF-A, CORE A*
- AAAI: CCF-A, CORE A*

- WWW: CCF-A, CORE A*
